# SellerPipe

**By Wyrmspire**

SellerPipe is a managed ETL pipeline that pulls reports from the **Amazon SP-API** and
lands them in **Google BigQuery** automatically — on a schedule, so sellers and the teams
behind them can query clean, ready-to-use data without building or maintaining a pipeline.

🌐 **Live site:** [sellerpipe.xyz](https://sellerpipe.xyz)

## What it does

- **Scheduled SP-API report syncs** — orders, sales, inventory, settlements, returns, and more.
- **Direct load into your own BigQuery** — you keep full ownership of the data.
- **Normalized, query-ready tables** — we handle SP-API quirks, retries, and schemas.
- **Multi-account** — manage many seller accounts from one place.
- **API access** — trigger syncs, check status, and pull data programmatically.
